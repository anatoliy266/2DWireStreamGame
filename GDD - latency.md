# Latency (Integrity)
    

## Геймплейная роль:
Latency задаёт уровень допустимого риска:
    высокий Latency 
    низкий Latency 

## Геймдизайнерская роль
Latency нужна, чтобы зрители чувствовали риск
и принимали простые решения между сейвом и атакой,
а на стриме периодически возникали короткие визуальные триггеры
(например, “сгоревший узел” с ником игрока в отдельном оверлее).
