# The Hops — Network Infiltration Protocol (GDD)

## 1. Назначение системы
**The Hops** — это центральная игровая структура, описывающая процесс прохождения «подземелья» (сетевых слоев). Это путь рейда от внешней границы сети (Firewall) до её ядра (Legacy Mainframe). 

Система вдохновлена прогрессией *Darkest Dungeon*: 
*   **Ресурсы конечны:** Integrity (HP) не восстанавливается на протяжении всего пути.
*   **Нарастающее напряжение:** Чем глубже рейд, тем выше риск Blackout из-за сложности комбо.
*   **Цена ошибки:** Каждая потерянная единица Integrity в первой комнате — это критическая нехватка выживаемости на боссе.

## 2. Структура слоев (The Layers)
Прохождение состоит из **3 слоев (слоев защиты)** и **Финального Ядра (Босса)**.

1.  **Hop 1: Edge Firewall (Внешний контур).** 3 комнаты с слабыми мобами (*Script Daemons*).
2.  **Hop 2: Protocol Deep Dive (Протокольный уровень).** 2 комнаты с элитными мобами (*Protocol Hunters*).
3.  **Hop 3: Core Gatekeepers (Стражи Ядра).** 1 комната с смешанной группой (1 элитный + 2 слабых).
4.  **Final Hop: The Legacy Mainframe (Ядро).** Битва с Боссом.

## 3. Зеркальная механика Буфера (Symmetry)
В системе **The Hops** атакующие слоты буфера работают так же, как защитные, но в обратную сторону:

*   **Защитные слоты (4 шт.):** В начале раунда за каждым слотом закрепляется **Игрок**. Если слот не закрыт командой `DEFEND` — игрок получает урон.
*   **Атакующие слоты (3 шт.):** В начале раунда за каждым слотом закрепляется **Моб** (от 1 до 3 врагов в комнате).
    *   **Слот Атаки 1:** Привязан к Мобу А.
    *   **Слот Атаки 2:** Привязан к Мобу Б.
    *   **Слот Атаки 3:** Привязан к Мобу В.
    
**Правило урона по врагам:**
команды автоматически распределяются по протоколу Авто-Маршрутизации буфера

## 4. Игровой цикл комнаты (Combat Loop)
Combat Loop повторяется до полной зачистки комнаты:

1.  **Initialization:** Рандомный выбор 4-х игроков для защиты и 1-3 мобов для атаки.
2.  **Input Phase (15-30 сек):** Чат закидывает команды. Происходит Combo Fusion и Overflow (урон по Latency).
3.  **Resolution Phase:**
    *   **Игроки атакуют:** Вычисляется урон по слотам Атаки 1, 2, 3. Привязанные к ним мобы теряют Integrity.
    *   **Мобы атакуют:** Мобы бьют по привязанным защитным слотам 1, 2, 3, 4. Назначенные игроки теряют Integrity, если слоты не закрыты.
4.  **Check:** Если мобы живы — новый раунд. Если все мобы мертвы — переход.

## 5. Переход между уровнями (The Transition)
После победы над всеми мобами в комнате:
*   **Integrity:** НЕ восстанавливается.
*   **Latency:** Все игроки получают `-50 ms` (охлаждение систем при переходе).
*   **Status Check:** Если игрок был в состоянии Blackout, он выходит из него.
*   **The Next Hop:** Загрузка следующей комнаты. Между слоями (например, после Hop 1 перед Hop 2) может быть пауза в 10 секунд для координации чата.

## 6. Финальная битва (The Boss Hop)
Когда рейд достигает **Legacy Mainframe**:
*   Босс занимает **все 3 атакующих слота** одновременно (у него три "порта" для атаки).
*   Урон в любой из 3-х атакующих слотов буфера наносит урон общему HP Босса.
*   Босс использует особые способности (`!kernel_panic`, `!broadcast`), которые могут блокировать защитные слоты игроков или встраивать вредоносные комбо (Combo -X2), увеличивающие урон по игрокам.

## 7. Условия Победы и Поражения

### Победа (System Breach):
Integrity Босса падает до 0. Чат видит финальный экран взлома, список выживших и общее количество нанесенного урона.

### Поражение (Vipe / Connection Lost):
Все активные игроки (Узлы) получили статус **TERMINATED** (0 Integrity).
*   *Драма момента:* Поскольку Integrity не восполняется, к Боссу рейд может подойти уже "побитым". Если в начале битвы с боссом осталось всего 2 живых игрока из 20, им придется закрывать 4 защитных слота вдвоем, что практически невозможно без моментального перегрева (Latency) и Blackout.

## 8. Геймдизайнерская цель
The Hops превращает простую забаву в чате в **стратегический марафон**. 
*   Игроки начинают ценить здоровье друг друга. 
*   Возникает "лидерство": "Парни, не бейте этого моба, он слабый, закройте щитами Варана, у него 5% HP!".
*   Чувство прогресса: переход от простых Script Daemons к "железному" Legacy Mainframe создает эпический масштаб для стрима.
