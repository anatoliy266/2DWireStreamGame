# 2. Entity — Enemies (GDD)

## А. Script Daemon (Weak Mob)
*   **Описание:** Простейший вирус-скрипт. "Шум" в системе.
*   **Поведение:**
    *   Атакует 1 случайный защитный слот слабой атакой.
*   **Особенность — DDOS Ping:**
    *   Если атака Демона проходит (слот открыт), игрок получает урон по Integrity **И** штраф **+20 ms Latency**.
    *   *Цель:* Забить каналы игроков мусором, провоцируя Blackout.

## Б. Protocol Hunter (Strong Mob)
*   **Описание:** Элитный перехватчик. Опасен для механики Буфера.
*   **Механика — Injection (Внедрение):**
    *   В начале хода Охотник "заражает" один из Защитных слотов своей командой.
    *   Слот помечается как **Corrupted**.
*   **Правило перекрытия:**
    *   Обычная защита (`Combo X1`) не снимает заражение (урон проходит частично).
    *   Только **Combo X2+** (две и более команды игроков в слоте) удаляет вирус Охотника.
*   **Цель:** Заставить игроков тратить больше действий на один слот.
