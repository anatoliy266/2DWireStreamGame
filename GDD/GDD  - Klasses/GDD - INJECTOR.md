# Injector / ДД
- Название класса: Injector
- Тип: ДД (урон)
- Ресурс: [HP / Latency]
- 2 атакующие способности (1 обычная, 1 по уязвимости) + 1 защитная

## Способности (Skills)
### 1. !payload

- Тип действия: атака
- Цель: враг
- Описание: Отправляет вредоносную нагрузку в узел врага, нанося базовый урон.
    - перезарядка: нет
    - стоимость: Y% Latency
- Геймплейная роль:
    Базовый стабильный урон, кнопка “бить когда нечего нажать”.
- Дизайнерская цель (фон-стрим):
    Сообщение: "Injector X отправляет payload в Z — узел получает урон."

### 2. !inject
- Тип действия: атака (по уязвимости)
- Цель: враг с эффектом Vulnerable
- Описание:
- Внедряется в открытую уязвимость узла, нанося повышенный урон и усиливая дебафф.
- Работает только если на цели есть уязвимость (например, после !traceback у Firewall).
    - перезарядка: X ходов
    - стоимость: Y% Latency / Exploit Points
- Геймплейная роль:
    Основной бурст-урон, награда за командную игру с танком.
- Дизайнерская цель (фон-стрим):
    Сообщение: "Firewall вскрыл уязвимость в Z — Injector X внедряется в дыру и наносит критический урон!"

### 3. !obfuscate (маскировка трафика)
- Защита через “зашумление”, а не уклонение
- Тип действия: защита
- Цель: себя
- Описание:
    Injector маскирует свой трафик, увеличивая Latency у босса при попытке атаковать его.
    Если босс в следующий ход выбрал Injector целью — атака наносит меньше урона и тратит Latency босса.
    - стоимость Y% Latency
- Геймплейная роль:
    Не 100% сейв, а “сделать атаку по тебе невыгодной”.
- Дизайнерская цель (фон-стрим): "Injector X зашумил трафик — атака босса захлебнулась в помехах."
