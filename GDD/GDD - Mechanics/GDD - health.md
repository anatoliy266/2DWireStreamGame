# 2. System Integrity (HP) — No Healing (GDD)

## 1. Назначение системы
**Integrity (Целостность)** — показатель физической стабильности соединения игрока.
Это **невосполнимый** ресурс. В игре **нет механики лечения**.
Единственный способ сохранить Integrity — предотвратить урон, закрывая защитные слоты в Буфере.

## 2. Термины
*   **Integrity (HP)** — прочность узла (0–100%).
*   **Impact (Удар)** — получение урона при открытом защитном слоте.
*   **Termination (Выбывание)** — состояние при 0 HP.

## 3. Механика получения урона
Урон рассчитывается персонально для каждого из 4-х игроков, назначенных на защитные слоты в текущем ходу.

**Формула для назначенного игрока:**
`DamageTaken = BossAttackDamage - (DefenseSlotPower * ComboMultiplier)`

*   Если слот **пуст** (`DefenseSlotPower = 0`), игрок получает полный урон (например, -40% HP за один удар).
*   Если слот **закрыт** мощным комбо, урон может быть полностью поглощен (0 Damage).
*   Если босс встроил свою команду в слот и она не была перекрыта более сильным комбо, урон увеличивается.

**Важно:** Игроки, не назначенные на слоты защиты в этом ходу, урон по HP не получают (но могут получить урон по Latency за ошибки).

## 4. Смерть (Termination)
При достижении **0% Integrity**:
1.  Игрок получает статус **TERMINATED**.
2.  Он немедленно отключается от сессии.
3.  Он не может писать команды до конца рейда (или до рестарта уровня).
4.  Его никнейм больше не выбирается для защитных слотов (нагрузка ложится на выживших).

## 5. Геймдизайнерская цель
*   **Высокие ставки:** Любая ошибка перманентна. Потерянные HP не вернуть.
*   **Альтруизм:** Игрок A видит, что Игрок B назначен целью, но у Игрока B высокий пинг или стан. Игрок A обязан кинуть `DEFEND`, чтобы спасти товарища, жертвуя своим действием атаки.
*   **Фокус огня:** Босс может несколько раз подряд выбирать одного и того же игрока целью слота, "добивая" слабое звено.
