# 3. Latency (Ping) — Overheat & Blackout (GDD)

## 1. Назначение системы
**Latency (Задержка)** — ресурс ограничения активности.
В отличие от Integrity, Latency восстанавливается со временем, но имеет жесткое наказание за превышение лимита — **Blackout (Стан)**.

Это единственный механизм, сдерживающий игроков от бесконечного спама команд.

## 2. Термины
*   **Ping (ms)** — текущее значение (0–200).
*   **Cost** — цена отправки команды (+10 ms).
*   **Vent** — пассивное снижение Latency в конце хода (-15 ms).
*   **Blackout (Перегрев)** — состояние полной блокировки на 2 хода.

## 3. Накопление
1.  **Action Cost:** Любая команда (`attack`, `defend`) = **+10 ms**.
2.  **Overflow Penalty:** Если команда вызвала переполнение буфера = **+40 ms** (Штраф за спам).

## 4. Состояния и Штрафы

| Ping (ms) | Состояние | Эффект |
| :--- | :--- | :--- |
| **0–99** | **Operational** | Штатный режим. Команды работают нормально. |
| **100–199**| **Unstable** | **High Ping.** Шанс 30%, что команда потеряется (не попадет в буфер, но Latency потратится). |
| **200+** | **CRITICAL** | **BLACKOUT (SYSTEM HALT).** |

## 5. Механика Blackout (Стан)
При достижении **200 ms**:
1.  Игрок получает статус **Blackout**.
2.  **Длительность:** Игрок пропускает **2 полных хода** (не может писать команды).
3.  В течение Blackout его Latency падает до 0 (система перезагружается).
4.  **Риск:** Если во время Blackout игрок окажется назначенным на защитный слот (Integrity GDD), он **не сможет** защитить сам себя. Его жизнь полностью зависит от команды.

## 6. Сброс (Vent)
*   **Активный ход:** -15 ms в конце хода.
*   **Пропуск хода (Idle):** -40 ms (если игрок ничего не писал).

## 7. Геймдизайнерская цель
*   Заставить игроков замолкать *до* критической отметки.
*   Наказание в 2 хода очень суровое — за это время можно пропустить фазу назначения в защиту и умереть без возможности ответить.
*   Создание ритма: "Бурст комбо" -> "Тишина/Остывание" -> "Бурст".
