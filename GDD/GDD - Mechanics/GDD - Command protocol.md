# 4. System — Command Protocol (GDD)

## 1. Назначение
Словарь допустимых команд. Парсер принимает только сообщения, соответствующие этому синтаксису.

## 2. Синтаксис
Формат: `[PREFIX] [ACTION] [TARGET] [DEBUFF]`

### Префиксы (Стоимость / Сила)
Определяют "вес" команды и затраты Latency.

| Префикс | Cost (Latency) | Power (Impact) | Примечание |
| :--- | :--- | :--- | :--- |
| **ping** | +5 ms | Low | Для запуска комбо или добивания. |
| **force** | +15 ms | Medium | Стандартное действие. |
| **sudo** | +30 ms | High | Мощное действие. Риск перегрева. |
| **brute**| +15 ms | Special | Дает бонус x2 только при Combo X3+. Иначе Low. |

### Действия (Actions)
Определяют, в какой слот полетит команда.

| Действие | Тип слота | Описание |
| :--- | :--- | :--- |
| **attack** | Attack (3) | Нанесение урона врагу. |
| **defend** | Defense (4)| Снижение урона по цели. |

### Цели (Targets)
*   `boss` / `mob` — для атаки.
*   `@username` — конкретный игрок (для защиты).
*   `self` — защита своего слота (если назначен).
*   `any` — автоматическое распределение в первый свободный слот.

## 3. Финишеры (Ultimates)
Занимают слот целиком. Не комбинируются. Лимит: 1 на ход.
*   `!rm -rf /` — (Attack) Массивный урон. Требует 0 ms Latency для запуска. Добавляет +100 ms после.
*   `!sys_lock` — (Defense) Полный иммунитет слота (игнорирует Injection и Kernel Panic).
