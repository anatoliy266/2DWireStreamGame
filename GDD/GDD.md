GAME DESIGN DOCUMENT: PROJECT "DPI" (Deep Packet Inspection)
Жанр: Roguelike-стратегия / Twitch-интеграция
Сеттинг: Cyberpunk / Network Infrastructure
Стиль: Темная абстракция (Topological Map / Terminal)
1. КОНЦЕПЦИЯ
Игроки в чате — это частицы мета-пакета (эксплойта), проникающего сквозь уровни защиты корпоративного мейнфрейма. Игра заимствует механику пошаговых боев и управления стрессом из Darkest Dungeon, заменяя фэнтези на элементы сетевой архитектуры.
2. ВИЗУАЛЬНЫЙ СТИЛЬ
Главный экран: Динамическая топологическая схема (узлы и связи).
Цветовая палитра: Черный фон, «фосфорный» зеленый (союзники), «аварийный» красный (враги), оранжевый (нагрузка).
Интерфейс: Стилизация под консоль администратора (ASCII-графика, HEX-коды, бегущие логи).
3. РОЛИ И КЛАССЫ (Зрители)
Каждый зритель подключается командой !connect и получает роль:
Класс	Роль	Ресурс	Ключевая особенность
FIREWALL	Танк	Shielding	Принимает на себя 70% входящего трафика.
TROJAN	ДД	Payload	Наносит высокий урон, но тратит собственное HP при атаках.
GC (Garbage Collector)	Саппорт	Optimization	Очищает логи (снижает стресс) и перераспределяет HP в группе.
ENCRYPTOR	Баффер	Entropy	Накладывает скрытность и щиты, защищая от мощных атак.
4. ОСНОВНЫЕ МЕХАНИКИ
4.1. Здоровье 
Individual Integrity (HP): У каждого узла свой запас здоровья.
4.2Награда
The Reward Pool: Финальная награда (валюта стрима) делится пропорционально оставшемуся HP среди выживших.
Disconnect: При 0% HP узел выбывает. Нагрузка на выживших увеличивается на 25%.
4.3. Аналог Стресса: Latency (Задержка)
Шкала, которая растет от вражеских атак и использования мощных способностей.
100% Latency: Происходит Kernel Panic.
Вариант А (Negative): Timeout (узел пропускает 2 хода).
Вариант Б (Positive): Overclock (скорость и урон х2, но HP падает каждый ход).
4.4. Позиционирование (The Hops)
Вместо рядов — дистанция до Ядра (Core).
Gateway (Шлюз): Первый контакт.
Proxy Layer: Слой поддержки.
Data Stream: Тыловая зона (ДД/Саппорты).
5. СТРУКТУРА "ПОДЗЕМЕЛЬЯ"
Рейд состоит из цепочки узлов (Hops), ведущих к Центру:
Stage 1: The Edge. Простые фильтры, пакеты-пустышки (404 ошибки).
Stage 2: DMZ. Системы обнаружения вторжений (IDS). Босс: The Sandbox (Песочница).
Stage 3: The Core. Финальный босс: Legacy Mainframe (Монстр из запутанных связей и старого кода).
6. СПОСОБНОСТИ (Skills)
FIREWALL
!intercept — Перехватить следующую атаку на себя.
!packet_filter — Бафф на сопротивление урону для всей группы.
TROJAN
!brute_force — Мощный удар (шанс 10% вызвать критическую ошибку у врага).
!inject — Накладывает эффект "Утечки памяти" (периодический урон).
GC (Garbage Collector)
!defrag — Выравнивает HP между двумя союзниками.
!flush_logs — Снижает Latency (Стресс) выбранной цели.
7. ТЕХНИЧЕСКИЙ СТЕК (Рекомендация)
Frontend: React + React Flow (для отрисовки графов).
Backend: Node.js + Socket.io (для связи с Twitch API в реальном времени).
Animation: Framer Motion для эффектов летящих пакетов и глитчей.
